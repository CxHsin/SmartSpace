# SmartSpace Project Overview

## Overview

SmartSpace 是一款面向个人用户的 Windows 桌面效率工具。它通过全局快捷键快速唤出一个左右分栏窗口：左侧用于管理带分类和截止日期的待办任务，右侧用于直接嵌入并操作第三方传统桌面应用。应用采用本地优先模式，不要求账号或云服务。

## Goals

1. 已启动的 SmartSpace 能在用户按下全局快捷键后 3 秒内显示，并出现在快速模式上次使用的位置。
2. 用户可以完整管理任务、单层分类和截止日期，并通过智能视图快速找到需要处理的任务。
3. 用户可以添加任意传统 Windows 桌面应用，并在右侧标签页中尝试交互式嵌入其主窗口。
4. 所有个人数据保存在本机，并可通过带版本号的备份文件完整导出和恢复。

## Core User Flow

1. 用户启动 SmartSpace；应用按设置常驻系统托盘。
2. 用户按全局快捷键，在上次移动的位置唤出快速窗口。
3. 用户在左侧查看“今天”“即将到期”“全部”“已完成”或某个分类中的任务。
4. 用户快速添加任务，并按需设置所属分类和截止日期。
5. 用户在右侧选择已配置应用或添加一个 `.exe`。
6. SmartSpace 启动该进程、寻找其主窗口，并尝试将窗口嵌入当前标签页。
7. 用户在多个应用标签页之间切换；同一时间只显示一个嵌入窗口。
8. 用户关闭窗口后，SmartSpace 根据设置留在托盘或完全退出。

## Features

### Tasks

- 创建、编辑、完成、恢复和删除任务。
- 每个任务包含标题、完成状态、可选截止日期和一个所属分类。
- 删除任务后提供短暂撤销。
- 分类支持创建、重命名、手动排序和删除。
- 系统内置不可删除的“收件箱”，用于接收未分类任务或被迁移的任务。
- 提供“今天”“即将到期（未来 7 天）”“全部”“已完成”四个智能视图。
- 分类视图中的任务支持手动排序；智能视图按截止日期排序。
- 过期任务使用克制的警示样式标记，不发送系统提醒。

### Embedded Applications

- 用户通过文件选择器添加任意传统桌面应用 `.exe`。
- 右侧使用标签页管理多个已打开应用，同一时间展示一个应用窗口。
- SmartSpace 启动应用后，尝试通过 Windows 窗口句柄将其主窗口嵌入容器。
- 标签页支持重新启动、重试嵌入、在外部打开和关闭。
- 嵌入能力属于实验性功能，不保证所有 Windows 应用兼容。
- 商店应用、管理员权限应用、多进程启动器、特殊渲染程序和多窗口程序可能无法正确嵌入。

### Desktop Experience

- 快速模式：全局快捷键显示或隐藏，失焦自动隐藏，并记住上次位置。
- 常规模式：作为可移动、缩放和最小化的普通窗口运行。
- 两种模式分别保存窗口位置和尺寸；显示器变化后将窗口校正到可见区域。
- 默认关闭到系统托盘，可在设置中改为完全退出。
- 提供开机自动启动开关、主题设置和可修改的全局快捷键。

### UI and Micro-interactions

- 前端采用安静、紧凑、适合高频操作的工作台视觉，不使用营销页式的大标题、装饰卡片或过度动画。
- 参考并按需采用 Amicro 的 React 微交互组件，用于任务完成、标签页切换、加载、成功、错误和撤销反馈。
- 微交互必须解释状态变化或提升操作反馈，不能仅用于装饰，也不能延迟任务录入或应用切换。
- 所有动画遵循系统“减少动态效果”偏好；关闭动画后，功能、层级和反馈仍然完整。
- 高频操作支持键盘与清晰焦点状态，图标按钮提供可访问名称和工具提示。

### Local Data and Backup

- 无账号、无云同步，业务数据保存在本机 SQLite 数据库。
- 支持将任务、分类、应用配置和设置导出为带版本号的 JSON 文件。
- 导入采用完整替换；导入前自动创建恢复点，失败时保持原数据不变。

## Scope

### In Scope

- Windows 专用桌面应用。
- 单用户、本地优先的数据模型。
- 任务、单层分类、截止日期和四个智能视图。
- 传统桌面应用的实验性交互式窗口嵌入。
- 快速窗口、常规窗口、系统托盘、全局快捷键和开机启动。
- 本地导入、导出和恢复点。

### Out of Scope

- 账号、云同步、协作和移动端。
- 系统提醒、重复任务、多标签和多级分类。
- 网页嵌入、小组件或快捷链接网格。
- 同时分屏显示多个第三方应用窗口。
- 对所有 Windows 应用提供兼容性保证。
- 保存或同步第三方应用内部状态。
- 纯展示型的复杂 3D 卡片、滚动特效和持续循环装饰动画。

## Success Criteria

1. 用户能完成任务和分类的全部核心操作，重启应用后数据仍然正确。
2. 四个智能视图对今天、未来 7 天、过期和已完成任务的归类准确。
3. 快速窗口能通过全局快捷键稳定显示和隐藏，并在多显示器变化后保持可见。
4. 兼容测试程序能在右侧容器内接收鼠标和键盘输入，并随窗口缩放。
5. 不兼容应用不会导致 SmartSpace 卡死、崩溃或损坏任务数据，并显示可恢复的失败状态。
6. 导出的备份能在干净数据库中完整恢复任务、分类、应用配置和设置。
